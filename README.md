# PICKFILM
### 고민은 짧게, 감상은 길게.

원하는 감상 경험과 시청 조건을 바탕으로 영화를 최대 3편 추천하고,
최종 한 편을 결정하도록 돕는 OTT 영화 선택 서비스입니다.

- 서비스: https://pickfirm.netlify.app
- GitHub: https://github.com/JungAh3/pickfilm

## 주요 기능

- 감상 경험 선택: 기분 전환, 위로, 웃음, 몰입, 여운
- 회피 요소 선택: 잔인한 묘사, 공포·위협, 느린 전개, 무거운 분위기
- 선호 장르 및 시청 시간 선택
- 이용 OTT 복수 선택
- 조건에 맞는 영화 최대 3편 추천
- 영화 상세 정보, 추천 이유, OTT 아이콘 표시
- 추천 영화 비교
- 이미 표시한 후보를 제외한 재추천
- 원픽 선정 및 최종 결정
- 모바일 화면 지원

## 추천 방식

1. 한국 구독형 OTT 제공 정보가 있는 후보를 확인합니다.
2. 이용자가 선택한 OTT와 상영시간 조건으로 필터링합니다.
3. 선택한 회피 요소가 미확인인 영화도 제외합니다.
4. 원하는 감상 경험과 관련된 영화에 점수를 계산합니다.
5. 점수순으로 최대 3편을 추천합니다.

점수 비중은 감상 경험 50%, 장르 30%, 평점 20%입니다.
장르를 선택하지 않으면 감상 경험과 평점의 비중을 재계산합니다.
평점은 평가 참여 수를 반영해 보정합니다.

점수는 후보 정렬을 위한 값이며 이용자의 만족 확률이 아닙니다.
조건에 맞는 영화가 부족하면 조건을 자동으로 완화하지 않습니다.

## 로컬 실행

Node.js와 npm이 설치된 환경에서 실행합니다.
다음 명령어는 Windows PowerShell 기준입니다.

### 패키지 설치

```powershell
npm.cmd ci
```

### 환경 변수

프로젝트 최상위에 `.env` 파일을 만들고 설정합니다.

```env
TMDB_READ_TOKEN=YOUR_TMDB_API_READ_ACCESS_TOKEN
```

실제 토큰은 GitHub에 업로드하지 않습니다.
브라우저 코드에 노출되지 않도록 `VITE_` 접두사를 사용하지 않습니다.

### 서버용 터미널

```powershell
npx.cmd netlify functions:serve --port 9999
```

### 화면용 터미널

별도의 터미널에서 실행합니다.

```powershell
npm.cmd run dev
```

접속 주소: http://127.0.0.1:5173

Vite의 프록시 설정으로 서버 함수 요청을 9999번 포트에 전달합니다.

## 테스트 및 빌드

```powershell
node --test tests/recommendations.test.js
npm.cmd run build
```

추천 계산 테스트 7개를 포함합니다.

- OTT 단일·복수 선택 필터
- 상영시간 경계값
- 회피 요소 미확인 처리
- 재추천 후보 제외
- 조건 불충족 시 빈 결과 반환
- 최대 3편 제한

테스트는 추천 계산을 검증하며,
외부 제공 정보나 편집 태그의 정확성을 보장하지 않습니다.

## 배포 설정

GitHub 저장소를 Netlify에 연결합니다.

- Build command: `npm run build`
- Publish directory: `dist`
- Functions directory: `netlify/functions`
- 환경 변수: `TMDB_READ_TOKEN`

서버 함수에서 사용할 수 있도록 환경 변수에 Functions 범위를 포함합니다.
환경 변수 변경 후에는 다시 배포합니다.

## 현재 범위와 한계

- 선정된 영화 후보 30편 안에서 추천합니다.
- 후보 목록과 감상 태그는 수동 관리합니다.
- 영화 정보와 OTT 제공처는 API로 조회합니다.
- 일부 회피 요소는 아직 미확인 상태입니다.
- 느린 전개·무거운 분위기는 주관적인 편집 기준입니다.
- OTT 정보는 실제 서비스의 제공 현황과 차이가 있을 수 있습니다.
- 한국의 구독형 제공 목록을 사용하며 대여·구매는 제외합니다.
- OTT 직접 재생 연결은 제공하지 않습니다.
- 최종 선택은 새로고침 후 유지되지 않습니다.
- 로그인, DB 저장, 예약 수집, 리뷰 본문 수집은 구현하지 않았습니다.

## 데이터 출처

- 영화 정보·포스터·평점: TMDB
- OTT 제공 정보: JustWatch, TMDB API를 통해 조회
- 일부 관람 안내: 영국 BBFC
- 감상 경험 태그: 줄거리 기반 PICKFILM 초기 편집 분류

This product uses the TMDB API but is not endorsed or certified by TMDB.

서비스 내 소개 영역에 TMDB 로고와 출처 안내를 표시합니다.
관람 안내를 참고한 영화는 상세 화면에서 해당 출처를 확인할 수 있습니다.
